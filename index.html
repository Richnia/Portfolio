⋄ Assistant IA éducatif pour étudiants

En construction

Objectif du projet

L’objectif est de créer un assistant IA spécialisé dans l’éducation, capable d’accompagner les étudiants dans leurs études et de leur faire gagner du temps dans leurs recherches et leurs révisions. L’assistant sera notamment conçu pour travailler à partir des cours et documents fournis par l’étudiant afin de proposer une aide adaptée à son programme d’études. La plateforme permettra à chaque étudiant de renseigner son niveau d’études et sa filière afin de personnaliser son expérience. L’étudiant pourra notamment importer un document, comme un cours au format PDF. L’assistant pourra ensuite analyser le contenu du document et proposer : des résumés clairs et structurés ; des fiches de révision ; des questions de compréhension ; des quiz et QCM ; des exercices de révision ; des simulations d’évaluation ; des explications sur les notions présentes dans le document ; un suivi de la progression et des résultats.

🔧 Technologies utilisées

  • HTML
  • CSS
  • JavaScript
  • Python
  • API REST
  • Base de données MySQL
  • XAMPP
